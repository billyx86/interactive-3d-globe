# Interactive 3D Globe

A polished interactive 3D globe web app with real-time day/night cycle, clickable city markers, and live world news.

## Stack
- TanStack Start + Vite + React 19
- three.js + @react-three/fiber + drei
- Tailwind CSS v4

## Features
1. Interactive 3D Earth with orbit controls
2. Real-time day/night based on UTC sun position
3. Clickable major world cities
4. Live news feed (RSS with curated fallback)
5. Dark polished UI

## Run
```bash
npm install
npm run dev
```
Serves on 0.0.0.0:8080
